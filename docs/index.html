Capabilities

Built for reliable, real-time detection

A focused feature set that keeps the model honest and the user informed.

AI

Fake News Detection

Binary classification (Real / Fake) powered by a trained Logistic Regression model.

NLP

Natural Language Processing

Cleaning, lowercasing, URL/HTML removal and tokenization before vectorization.

TF

TF-IDF Vectorization

Converts cleaned text into weighted numerical features for the classifier.

RT

Real-Time Prediction

Async fetch-based prediction with spinner and live character counter.

%

Confidence Score

Per-class probabilities with a low-confidence flag for uncertain inputs.

Setup

Installation

1

Clone the repository

git clone https://github.com/shubham17290/Shubham_Maurya_PBEL_3.0.git
cd Shubham_Maurya_PBEL_3.0
2

Create a virtual environment

python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate
3

Install dependencies

pip install -r requirements.txt
4

Run the application

python app.py
# open http://127.0.0.1:5000
